# Flow Kids - Educação Financeira Gamificada

## Conceito: O Primeiro "Banco" para Crianças no Brasil

### Visão
Ensinar educação financeira para crianças através de gamificação, preparando a próxima geração de brasileiros financeiramente conscientes.

## Como Funciona

### Para os Pais (App Principal Flow)
- **Controle Total**: Define mesadas, recompensas, metas
- **Acompanhamento**: Vê progresso dos filhos em tempo real
- **Transferências**: Envia dinheiro para "conta" das crianças
- **Relatórios**: Analytics do comportamento financeiro infantil

### Para as Crianças (Flow Kids)
- **Conta Virtual**: Saldo próprio gerenciado pelos pais
- **Tarefas Gamificadas**: Ganham dinheiro completando responsabilidades
- **Metas Visuais**: Economizam para brinquedos, jogos, experiências
- **Conquistas**: Sistema de badges por bons hábitos financeiros

## Funcionalidades Educativas

### Sistema de Recompensas
- **Tarefas Domésticas**: R$ 3-15 por atividade
- **Notas Escolares**: Bônus por bom desempenho
- **Comportamento**: Pontos extras por atitudes positivas
- **Ajuda Mútua**: Irmãos que se ajudam ganham mais

### Educação Financeira
- **Conceito de Juros**: "Sua poupança cresce sozinha!"
- **Orçamento Simples**: "Quanto você pode gastar por semana?"
- **Priorização**: "O que é mais importante: doce hoje ou brinquedo amanhã?"
- **Compartilhamento**: "Que tal ajudar uma instituição de caridade?"

### Gamificação
- **Níveis**: Poupador Iniciante → Expert → Mestre
- **Conquistas**: "Primeira Meta", "30 Dias Poupando", "Irmão Herói"
- **Desafios**: "Economize R$ 50 este mês"
- **Ranking Familiar**: Competição saudável entre irmãos
