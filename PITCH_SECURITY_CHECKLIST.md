# Flow Ecosystem - Checklist de Segurança para Pitch

## ⚠️ ATENÇÃO: NUNCA APRESENTAR SEM NDA ASSINADO

---

## 1. PRÉ-REUNIÃO (24h antes)

### Documentação Legal
- [ ] NDA enviado via DocuSign/ClickSign
- [ ] Link de assinatura enviado para Daniel
- [ ] Prazo de 48h para assinatura antes da reunião
- [ ] Backup do documento assinado em nuvem segura
- [ ] Verificação de autenticidade da assinatura digital

### Preparação Técnica
- [ ] Demo environment isolado preparado
- [ ] Dados sensíveis removidos/mascarados
- [ ] Versão de apresentação sem código-fonte
- [ ] Screenshots para backup (caso demo falhe)

### Equipe Briefada
- [ ] Toda equipe ciente das regras de confidencialidade
- [ ] Definição clara do que pode/não pode ser mostrado
- [ ] Pessoa designada para controlar acesso técnico

---

## 2. DURANTE A REUNIÃO

### Controle de Acesso
- [ ] Verificar identidade do investidor
- [ ] Confirmar assinatura do NDA antes de começar
- [ ] Ambiente físico/virtual seguro
- [ ] Gravação/screenshots expressamente proibidos

### Apresentação Controlada
- [ ] Mostrar apenas funcionalidades públicas
- [ ] **NÃO MOSTRAR:**
  - Código-fonte ou arquitetura
  - Algoritmos de OCR em detalhes
  - Dados reais de usuários
  - Integrações bancárias específicas
  - Métricas financeiras exatas
  - Roadmap técnico detalhado

### O que PODE ser mostrado:
- [ ] Interface do usuário (UI/UX)
- [ ] Fluxo geral das funcionalidades
- [ ] Demonstração de valor para o usuário
- [ ] Visão geral do produto
- [ ] Proposta de negócio
- [ ] Tamanho de mercado
- [ ] Modelo de receita

---

## 3. INFORMAÇÕES PROTEGIDAS

### 🔒 NÍVEL ULTRASSECRETO
- Algoritmos proprietários de OCR
- Integrações com APIs bancárias
- Código-fonte completo
- Arquitetura de segurança
- Dados de performance real
- Estratégias técnicas específicas

### 🔒 NÍVEL SECRETO
- Roadmap técnico detalhado
- Parcerias em negociação
- Métricas de usuário específicas
- Custos operacionais exatos
- Planos de contratação

### 🔒 NÍVEL CONFIDENCIAL
- Estratégia de pricing detalhada
- Análise competitiva profunda
- Projeções financeiras específicas
- Planos de expansão geográfica

---

## 4. PROTOCOLO DE EMERGÊNCIA

### Se Daniel pedir informações protegidas:
1. **Pause a apresentação**
2. **Explique:** "Esta informação está coberta pelo NDA e preciso consultar nossa equipe jurídica"
3. **Agende follow-up:** "Posso compartilhar isso numa próxima reunião com termos específicos"
4. **Continue** com informações públicas

### Se houver tentativa de gravação:
1. **Interrompa imediatamente**
2. **Solicite exclusão** do material gravado
3. **Documente o incidente**
4. **Avalie continuidade** da reunião

---

## 5. PÓS-REUNIÃO

### Documentação
- [ ] Ata da reunião com pontos discutidos
- [ ] Lista de informações compartilhadas
- [ ] Próximos passos acordados
- [ ] Prazos para feedback/decisão

### Follow-up Seguro
- [ ] E-mails através de canais criptografados
- [ ] Compartilhamento via plataforma segura
- [ ] Informações adicionais apenas mediante solicitação
- [ ] Manter log de todas as comunicações

---

## 6. SINAIS DE ALERTA

### 🚨 Interromper apresentação se:
- Daniel não assinou NDA
- Perguntas muito técnicas sobre algoritmos
- Solicitação de código-fonte
- Tentativa de gravação sem autorização
- Presença de pessoas não identificadas
- Pressão para revelar informações protegidas

### 🚨 Red flags do investidor:
- Evita assinar NDA
- Histórico de investimentos em concorrentes
- Equipe técnica muito presente (possível reverse engineering)
- Perguntas focadas em tecnologia vs negócio
- Pressa excessiva para ver detalhes técnicos

---

## 7. MATERIAIS SEGUROS PARA COMPARTILHAR

### ✅ Permitido:
- Pitch deck público (sem informações sensíveis)
- Vídeo demo geral (interface apenas)
- Plano de negócio high-level
- Análise de mercado
- Proposta de valor
- Modelo de receita geral

### ❌ Proibido:
- Código-fonte ou pseudocódigo
- Diagramas de arquitetura
- Documentação técnica
- Dados de performance
- Contratos com parceiros
- Análise competitiva detalhada
