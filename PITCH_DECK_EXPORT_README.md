## Como Usar

### Opção 1: Apresentação Online
1. Abra o arquivo `pitch-deck-export.html` no navegador
2. Use as setas do teclado ou barra de espaço para navegar
3. Funciona em qualquer navegador moderno

### Opção 2: Imprimir como PDF
1. Abra `pitch-deck-export.html` no Chrome/Firefox
2. Ctrl+P (ou Cmd+P no Mac)
3. Selecione "Salvar como PDF"
4. Configure para "Paisagem" se preferir
5. Terá um PDF com todos os 15 slides

### Opção 3: Conversão para PowerPoint
**Para converter para .pptx:**

1. **Via Online Tools:**
   - Acesse sites como SmallPDF, ILovePDF, ou PDF24Tools
   - Faça upload do PDF gerado
   - Converta PDF → PowerPoint

2. **Via Microsoft PowerPoint:**
   - Abra PowerPoint
   - File → Open → Selecione o PDF
   - PowerPoint converte automaticamente

3. **Via Google Slides:**
   - Faça upload do PDF no Google Drive
   - Abra com Google Slides
   - File → Download → Microsoft PowerPoint
