Objetivo: Dar vida à UI com SOM + ANIMAÇÕES e ligar todos os botões do fluxo de Portal/Jornada, mantendo o tracking para MVP mensurável.

## 1) SOUND DESIGN (UI Kit)
- Adicionar micro-sons (volume baixo) para: click, success, open/close, tick de respiração.
- Criar /public/audio com placeholders (ogg/mp3 curtos: 50–200ms).
  - ui_click, ui_success, ui_open, ui_close, breath_tick.
- Implementar módulo client/src/lib/sound.ts com:
  - preload dos sons (AudioContext ou Howler)
  - função play(name: 'ui_click'|'ui_success'|'ui_open'|'ui_close'|'breath_tick')
  - rate-limit (min 80ms entre plays) para evitar “cacofonia”
  - respeitar autoplay policy: só habilitar após primeiro gesto do usuário
- Toggle Global:
  - Botão “🔊/🔇 Som” no header/config
  - Persistir em localStorage (sound_enabled=true/false)
- Instrumentar eventos:
  - POST /api/events {event:'sound_toggle', value:true|false}
  - Contar clicks com {event:'ui_click_played'}

## 2) ANIMAÇÕES (leve e responsivo)

- Criar componente <BreathRing mode="446"> com tempos configuráveis e tick sonoro (breath_tick) no start/hold/expire.
- Microfeedback ao ganhar pontos: badge flutuante “+10” com fade/scale.

  - HLS (hls.js) + poster; fallback para <video> nativo.
  - Eventos enviados a /api/media/events: play, pause, quartile_25/50/75/complete, error.
  - Ao complete → mostrar CTA: “Fazer Check-in FEME” (aciona pontos e navega).

  - **Conversar**: abre chat IA real (já existente /api/ai/selfsession). Se ainda não existir, criar endpoint simples que retorna resposta do Claude 3 com base no contexto do portal atual.
