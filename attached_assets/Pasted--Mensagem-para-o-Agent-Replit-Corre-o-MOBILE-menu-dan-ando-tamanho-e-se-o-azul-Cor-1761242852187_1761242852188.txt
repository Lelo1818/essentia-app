> ### 3) “Dança” após a faixa azul (“Boa tarde… 7 dias seguidos”)
>
> **Causa provável:** reflow por **100vh** no iOS, **auto-resize** de textos e/ou **transform** em ancestrais do sticky.
>
> **Correções obrigatórias:**
>
> * Trocar `100vh` por **`100dvh`** (ou `100svh`) na página para eliminar variação do URL bar do iOS.
> * Fixar a **altura da faixa azul** para evitar “crescer/encolher”.
> * Garantir que nenhum ancestral do menu sticky tenha `transform`, `filter` ou `perspective`.
>
> **Código (CSS global):**
>
> ```css
> .page { min-height: 100dvh; overflow-x: hidden; }
> .hero-blue {
>   min-height: 64px; /* fixa */
>   display: flex; align-items: center;
> }
> .hero-title { font-size: 16px; line-height: 1.2; }
> ```
>
> **Ajustes TSX (onde a faixa azul é renderizada):**
>
> ```tsx
> <section className="hero-blue px-4">
>   <div className="hero-title">Boa tarde, continue sua jornada — 7 dias seguidos</div>
> </section>
> ```
