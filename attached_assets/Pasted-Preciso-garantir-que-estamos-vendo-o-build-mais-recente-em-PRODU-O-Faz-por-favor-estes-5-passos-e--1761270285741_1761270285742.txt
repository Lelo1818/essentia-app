Preciso garantir que estamos vendo o build mais recente em PRODUÇÃO. Faz por favor estes 5 passos e me confirma:

Rebuild de produção do client

# na raiz do projeto
npm run build --workspaces --if-present
# ou, se for monorepo com client/
cd client && npm run build


Subir o servidor em modo produção

# garantir NODE_ENV=production pra usar o serveStatic
NODE_ENV=production npm run start
# (ou o comando start que você usa aí no Replit)


(Patch simples pra vermos a versão no ar)

Adicionar no topo de client/src/main.tsx ou client/src/App.tsx:

// @ts-ignore
window.__BUILD_ID__ = import.meta.env.VITE_BUILD_ID || new Date().toISOString();
console.log("[BUILD]", window.__BUILD_ID__);


E no rodapé do layout (qualquer lugar visível), renderizar:

<div style={{fontSize: 10, opacity: 0.6, textAlign: 'center', padding: 8}}>
  build: {String((window as any).__BUILD_ID__ || 'dev')}
</div>


No replit/env de build, setar um id:

# exemplo
VITE_BUILD_ID=prod-2025-10-23-22h npm run build


Cache/PWA

Garantir que não há service worker antigo. Se tiver PWA, forçar unregister no client/src/main.tsx:

if ('serviceWorker' in navigator) {
  navigator.serviceWorker.getRegistrations().then(regs => regs.forEach(r => r.unregister()));
}


Já temos estes headers no server: Cache-Control: no-cache, no-store, must-revalidate ✅
