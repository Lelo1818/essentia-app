# ✨ Se quiser 1 melhoria **sem backend** (já hoje)

**Recomendações locais**: regras simples em JSON + hora do dia → “micro-passos” (sem IA/servidor).
Ex.: `client/src/lib/recs.json`

```json
[
  {"when":"morning", "mood":"contemplative", "text":"Respiração 4-4-6 + 1 linha de intenção"},
  {"when":"evening", "mood":"tired", "text":"3 gotas de gratidão + 1 alongamento guiado"}
]
```

E no componente (pseudocódigo):

```ts
import recs from "@/lib/recs.json";
const rec = recs.find(r => r.when === timeOfDay && r.mood === mood) ?? recs[0];
```

Resultado: **“motor de recomendações”** percebido pelo investidor, **sem custo de infra**.
