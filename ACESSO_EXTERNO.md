# Acesso Externo ao EduVie

## URLs de Acesso

### Replit Interno (Funcionando ✅)
- http://localhost:5000/eduvie

### Para Acesso Externo
1. **URL do Replit**: https://replit.com/@usuario/projeto
2. **Porta aberta**: A porta 5000 está configurada para aceitar conexões externas
3. **Rota EduVie**: `/eduvie`
