# Flow - Estratégia de Pricing e Concorrência

## Análise de Concorrentes Brasileiros (2025)

### GuiaBolso
- **Freemium**: Gratuito básico
- **Premium**: R$ 9,90/mês
- **Funcionalidades**: Controle básico, categorização manual, sem OCR

### Mobills
- **Gratuito**: Limitado a 2 contas
- **Premium**: R$ 12,90/mês
- **Premium+**: R$ 19,90/mês
- **Funcionalidades**: Orçamento, metas, sem automação avançada

### Organizze
- **Gratuito**: Funcionalidades básicas
- **Premium**: R$ 15,90/mês
- **Funcionalidades**: Planejamento, relatórios, interface datada

### MoneyLover
- **Gratuito**: Limitado
- **Premium**: R$ 24,90/mês
- **Funcionalidades**: Multi-moeda, sincronização

### Toshl Finance
- **Gratuito**: Básico
- **Pro**: R$ 29,90/mês
- **Funcionalidades**: Relatórios avançados, budgets

## Proposta de Pricing para Flow

### Tier Freemium - R$ 0/mês
- Dashboard básico
- Até 3 contas bancárias
- OCR limitado (5 documentos/mês)
- Categorização manual
- Relatórios básicos

### Tier Essencial - R$ 19,90/mês
- OCR ilimitado (holerite, faturas, extratos)
- Contas ilimitadas
- Gestão fiscal básica (IR)
- Metas e planejamento
- Suporte via chat

### Tier Premium - R$ 39,90/mês
- Tudo do Essencial +
- NFS-e ilimitadas para autônomos
- Análise de investimentos
- Fluxo de caixa preditivo
- Relatórios avançados para contabilidade
- Integração com contadores

### Tier Business - R$ 79,90/mês
- Tudo do Premium +
- Multi-usuários (até 5)
- API para integração
- Suporte prioritário
- Consultoria fiscal mensal
- Dashboard executivo

## Justificativa de Pricing

### Por que R$ 19,90 (vs R$ 99)?

**Mercado Brasileiro:**
- Renda média: R$ 2.800
- Concorrentes: R$ 9,90 - R$ 29,90
- Penetração: Preço acessível acelera adoção

**Valor Percebido:**
- OCR automático = economia 2h/mês
- Gestão fiscal = economia R$ 200/mês contador
- ROI: 10x em economia vs custo

**Estratégia de Crescimento:**
1. **Freemium** → captura usuários
2. **R$ 19,90** → conversão alta (sweet spot)
3. **R$ 39,90** → profissionais/autônomos
4. **R$ 79,90** → pequenas empresas

## Projeção de Receita

### Cenário Conservador (Ano 1)
- 50.000 usuários freemium
- 5.000 usuários Essencial (R$ 19,90)
- 1.000 usuários Premium (R$ 39,90)
- 200 usuários Business (R$ 79,90)

**ARR**: R$ 2.3MM (primeiro ano)

### Cenário Otimista (Ano 3)
- 500.000 usuários freemium
- 75.000 usuários Essencial
- 15.000 usuários Premium
- 3.000 usuários Business

**ARR**: R$ 35MM (terceiro ano)

## Diferenciais vs Concorrência

### Flow vs GuiaBolso/Mobills
- **OCR automático** vs digitação manual
- **Gestão fiscal completa** vs básica
- **UX moderna** vs interface datada
- **Preço competitivo** vs funcionalidades premium

### Vantagens Competitivas
1. **Tecnologia**: Único com OCR completo no Brasil
2. **Abrangência**: Todos aspectos financeiros em um app
3. **Automação**: Reduz trabalho manual em 80%
4. **Compliance**: Totalmente adequado à legislação brasileira

## Estratégia de Lançamento

### Fase 1 (Meses 1-6): Freemium
- Foco em crescimento de usuários
- Feedback e melhorias
- Marketing orgânico

### Fase 2 (Meses 7-12): Monetização
- Lançamento tiers pagos
- Parcerias com contadores
- Marketing pago

### Fase 3 (Ano 2+): Expansão
- Novos produtos (crédito, investimentos)
- Mercado B2B
- Expansão LATAM

**R$ 19,90/mês** é o preço ideal para o mercado brasileiro:
- Competitivo vs concorrentes
- Acessível para classe média
- Alto valor percebido pelo OCR
- Margem saudável para crescimento
